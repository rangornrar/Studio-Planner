Choisir une base

Prenez le preset qui ressemble le plus à votre intention de départ.

Le but n'est pas de trouver un preset parfait, mais une base assez proche pour gagner du temps sur le placement, la circulation et la lecture générale du set.

Sauvegarder votre méthode

Enregistrez votre propre version quand le setup devient récurrent.

Une fois votre variante stabilisée, utilisez le menu Presets pour conserver cette implantation et la rouvrir plus tard dans ce navigateur.

Vérifier avant partage

Mesurez puis exportez seulement la version qui vous sert vraiment.

Activez Mesure pour contrôler les distances clé, puis sortez un PNG, un PDF ou une image copiée selon la personne qui doit relire le plan.

Passer à l'action

Chargez une base, adaptez la scène, mesurez puis sauvegardez votre version.

Chaque élément peut être déplacé, tourné, supprimé ou exporté. Le preset sert de départ, pas de limite.
